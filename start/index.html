トレーニング記録アプリ
はじめかた

お客様のトレーニング記録・総重量・体重の推移を、スマホで管理してお客様と共有できるアプリです。費用は無料、Googleアカウントだけで使えます。最初の設定は約20分（パソコンがおすすめ）。

① アプリをコピーする

Googleにログインした状態で押し、「コピーを作成」を押してください。データはすべてあなたのGoogleドライブに保存され、ほかの人からは見えません。

② 初期設定

  1. コピーしたスプレッドシートのメニュー「拡張機能」→「Apps Script」
  2. 上の関数の選択欄で「setup」を選んで「▷ 実行」
  3. 「承認が必要です」→「権限を確認」→ 自分のアカウント →「詳細（上級者）」→「（安全ではないページ）に移動」→「許可」
「Googleで確認されていません」と出ますが、あなたのアカウントの中だけで動くプログラムなので問題ありません。

③ 公開する

  1. Apps Script 右上の「デプロイ」→「新しいデプロイ」
  2. 歯車 ⚙ →「ウェブアプリ」
  3. 次のユーザーとして実行：自分　／　アクセスできるユーザー：全員
  4. 「デプロイ」（承認が出たら②と同じように許可）
  5. 「ウェブアプリのURL」（最後が /exec）をコピー

④ スマホに入れる

  1. スプレッドシートの「設定」シートの B2 に、③のURLを貼り付け
  2. B4 に出る「管理画面のURL」を自分のスマホに送る（LINEのKeepメモなど）
  3. スマホで開いて「ホーム画面に追加」
    iPhone：共有ボタン（□↑）→「ホーム画面に追加」／Android：︙ →「ホーム画面に追加」
管理画面のURLは誰にも教えないでください。漏れたときは、メニュー「トレーニング記録 → 管理用キーを作り直す」。

⑤ 使い始める

  • 「＋ 顧客を追加」でお客様を登録 →「LINEで送る」で専用URLを送る
  • 記録は「記録入力」から。メモから貼り付け（SQ 60×5 のようなメモを貼ると自動入力）や「このメニューで入力」が便利です
  • お客様が体重・自主トレ・日記を送ると、あなたのGmailに通知が届きます

データ提供のお願い（任意）

配布者は、トレーニングの効果を調べるために名前を除いた統計データを集めています。協力してもらえる場合だけ設定してください。協力しなくても、すべての機能を使えます。

送られるもの（お客様が同意した人の分だけ）
所在地（市区町村まで）・年代（5歳刻み）・性別・身長・体重と体脂肪の記録

送られないもの
名前・番地・URL・メモ・日記・自主トレ・トレーニング内容。お客様はランダムな記号で表され、名前はわかりません。
  1. お客様に説明して同意をもらう
  2. 同意した方だけ、プロフィール編集で「データ提供に同意あり」にチェック
  3. スプレッドシートのメニュー「トレーニング記録 →データ提供をオンにする」（以後1日1回、自動で送信）
  4. やめるときは「データ提供をオフにする」。送ったデータも削除されます

新しい版をもらったとき

  1. Apps Script の コード.gs と App.html を新しいものに貼り替えて保存
  2. 「setup」を一度実行（データは消えません）
  3. 「デプロイ」→「デプロイを管理」→ ✏ → バージョン「新バージョン」→「デプロイ」
    「新しいデプロイ」にするとURLが変わってしまうので注意
